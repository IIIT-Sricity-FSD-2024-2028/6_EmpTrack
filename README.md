# 6_EmpTrack
FFSD Project – Attendance, Leave and Work Allocation Platform
Problem Statement:Attendance,Leave and Work            Allocation Platform
 In many organizations, attendance tracking, leave management, and work allocation are handled using disconnected tools or manual processes. This leads to:
•	Inaccurate attendance records
•	Delays in leave approvals
•	Lack of transparency between employees, team leads, and HR
•	Difficulty in tracking assigned work and team performance
•	Inefficient handling of complaints and policy enforcement
To address these challenges, this project proposes a centralized web-based platform that integrates attendance, leave, and work allocation into a single system with role-based access.
Project Objective:
The objective of this system is to:
•	Automate attendance marking and tracking
•	Streamline leave application and approval workflows
•	Enable structured work/task allocation
•	Improve coordination between Employees, Team Leads, and HR
•	Provide accurate reports for decision-making
Identified Actors:
The system involves three primary actors:
Employee– Records attendance, applies for leave, and interacts with assigned tasks
Team Lead– Supervises team attendance, manages team leave, and allocates work
HR– Manages organizational policies, handles complaints, and generates reports
Actor Features:
Employee Features:
1.	Track Attendance 
Mark Daily Attendance: Record daily check-in and check-out times
           View Attendance History: Access past attendance record
         Apply Regularization: Submit correction requests for attendance            discrepancies
          View Attendance Status: Check approval status of attendance corrections
2.	Leave Operations
Submit Leave Request: Apply for leave with reason and date selection
View Leave Balance: Check available leave quota
Track Leave Status: Monitor approval or rejection updates
Cancel Leave Request: Withdraw leave request before approval
Respond to leave complaint:Respond to complaints raised for taking leave without prior approval and Provide justification or explanation for unapproved leave cases
3.	  Task Interacation
View Assigned Tasks: Access tasks allocated by the Team Lead
           Update Task Progress: Modify task status (In Progress, Completed)
Communicate with Team Lead: Send task-related queries or updates
Team  Lead Features
1.	Attendance Oversight
Monitor Team Attendance: View and review daily attendance records of team members
Attendance Regularization: Evaluate and take action on employee requests for attendance corrections
2.	Manage Team Leave
Review Leave Requests: Approve or Reject leave requests  of employee
Forward issue to HR: Escalate leave requests in emergency cases and  complaints
3.	Work Allocation 
Assign Tasks : Allocate work based on roles and workloadModify Task Assignments: Reassign or update tasks
Track Task Progress: Monitor completion status
4.	Generate Reports
Generate Team Attendance Reports: Create periodic reports summarizing team attendance records
Generate Leave Reports: Produce reports on team leave usage and approval status
Generate Task Progress Reports: Create detailed reports showing task status, completion percentage, pending tasks, and overall team productivity
HR Features
1.	Manage Policy
Create and Update Leave Rules: Set and change rules for different types of leave
Define  Attendance Rules: Decide working hours and rules for late coming or absences
Update Company Guidelines: Make changes to policies related to attendance and leave
2.	Handle Complaints
Manage and Resolve Complaints: Receive attendance or leave issues from employees or team leads, review the explanation and any supporting proof, take necessary corrective action, update records if required, and notify the employee about the final decision.
3.	Generate Reports
Create Attendance Reports: Prepare summaries of employee attendance
Create Leave Reports: Prepare reports on leave usage and balances
Create Work Reports: Generate reports showing task progress and employee performance
